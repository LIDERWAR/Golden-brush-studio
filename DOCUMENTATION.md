## 1. Общие сведения и бизнес-архитектура

Платформа **GB STUDIO** разработана как высоконагруженный представительский инструмент лидогенерации и позиционирования премиального архитектурно-строительного холдинга и авторского ателье.

### 1.1. Двойное позиционирование (Dual Positioning)
Проект решает две ключевые коммерческие задачи:

1. **Генерация B2B-контрактов на генподряд и Fit-Out (Фокус Натальи Попыкиной):**
   * Объекты масштабом от 500 до 15 000+ м²: корпоративные офисы класса A/B, штаб-квартиры, отели и рестораны (HoReCa), административно-бытовые комплексы (АБК) промышленных предприятий.
   * Конкурентные триггеры надежности: официальный допуск СРО, работа строго по ГОСТ и СНиП, безналичный расчет с НДС, фиксированная смета без скрытых доплат, гарантия 5 лет по договору.
   * Инструменты захвата: интерактивный 4-шаговый конфигуратор сметы, заказ презентационного кейса образцов фактур (**Architect Sample Box**) для проектных бюро, заказ выездного аудита главного инженера.

2. **Обоснование премиального чека через статус художника (Фокус Александра Попыкина):**
   * Александр Попыкин — основатель студии, признанный художник с непрерывной практикой с 1998 года (станковая живопись, монументальные рельефы, скульптурная керамика).
   * Статус автора первого ряда снимает ценовые возражения девелоперов и выводит компанию из конкуренции с «бригадами с Авито».
   * Онлайн-галерея оригинальных работ и Журнал мастерской (Work in Progress) с возможностью прямого бронирования полотен в корпоративные и частные коллекции.

### 1.2. Регламент дизайна («Анти-нейрослоп»)
В проекте строго соблюден кодекс архитектурной чистоты:
* **Типографика надстрочных подзаголовков (`.eyebrow`):** только благородный чистый текст. Категорически исключены рамки, цветные плашки, заливки, овальные «пилюли» (`border-radius: pill`) и иконки.
* **Кнопки действий (CTA):** только уверенный текстовый призыв к действию. Запрещены декоративные иконки стрелочек, щитов, калькуляторов и эмодзи внутри кнопок.
* **Лексика:** исключен дешевый маркетинговый жаргон («лид-магнит», «воронка», «квиз» на виду у заказчика) и псевдо-интеллектуальный сгенерированный текст.

```
                               ▼                      ▼
        ┌─────────────────────────────┐    ┌─────────────────────────────┐
        │        PostgreSQL 16        │    │    Telegram Bot Service     │
        │  (Изолированная БД лидов)   │    │  (Мгновенный пуш Наталье    │

                                           └─────────────────────────────┘
```

* **Серверный бэкенд:** Python 3.12+ / Django 5.x–6.0.
* **Интерфейс администрирования (CRM):** `django-jazzmin` с премиальной архитектурной темой графит/золото.
* **База данных:** SQLite (локальная разработка) / PostgreSQL 16 Alpine (production).
* **Фронтенд:** Vanilla HTML5, Vanilla CSS3 (собственная модульная дизайн-система токенов, адаптивная верстка от 320px до Ultrawide 4K), Vanilla JS (ES6+ асинхронные Fetch API).
* **Сетевой стек и контейнеризация:** Docker, Docker Compose, Nginx, Certbot (Let's Encrypt SSL).

## 4. Модели данных и внутренняя CRM

### 4.1. Приложение `leads` (Входящие обращения и воронка)
Центральный реестр всех клиентов компании. Модель `Lead`:

| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| `name` | `CharField(150)` | Контактное лицо (ЛПР / архитектор / коллекционер) |
| `company` | `CharField(200)` | Наименование компании, бюро или предприятия |
| `phone` | `CharField(50)` | Номер телефона (основной канал связи) |
| `email` | `EmailField` | Электронная почта для смет и КП |
| `object_type` | `CharField(100)` | Тип объекта: Офис А/B, Ресторан/Отель, АБК завода, Ритейл |
| `area_range` | `CharField(100)` | Площадь помещения (например, `1500–5000 м²`) |
| `service_needed`| `CharField(255)` | Требуемые работы / выбранный класс отделки |
| `timeline` | `CharField(100)` | Планируемые сроки сдачи объекта |
| `estimated_cost`| `CharField(100)` | Предварительная расчетная смета из калькулятора |
| `message` | `TextField` | Дополнительное ТЗ, адрес для Sample Box или название картины |
| `source` | `CharField(50)` | Источник: `quiz`, `sample_box`, `audit_form`, `art_inquiry`, `quick_call` |
| `status` | `CharField(30)` | Воронка: `new`, `in_progress`, `audit_booked`, `kp_sent`, `contract`, `archived` |
| `manager_notes` | `TextField` | Служебные заметки Натальи по ходу переговоров |
| `created_at` | `DateTimeField` | Время фиксации заявки в системе |

### 4.2. Приложение `projects` (Объекты Fit-Out)
* `ProjectCategory`: Категории объектов (`Офисы и штаб-квартиры`, `HoReCa`, `Предприятия и заводы`, `Девелопмент`).
* `Project`:
  * Площадь (`area_sqm`), год реализации (`year`), сроки выполнения (`duration`).
  * `scope_of_work`: Перечень выполненных строительно-монтажных и художественных работ (разделяются `;` для автоматического вывода маркированного списка).
  * `image` / `image_url`: Поддержка как загрузки файлов через админку, так и указания пути.

### 4.3. Приложение `gallery` (Арт-Ателье)
* `ArtworkCategory`: Направления (`Монументальная живопись`, `Интерьерная керамика`, `Авторская графика`).
* `Artwork`:
  * Размеры (`dimensions`), материалы и техника (`medium`), стоимость (`price`).
  * Статус произведения: `available` (в мастерской), `in_collection` (в частной коллекции), `reserved` (зарезервировано).
  * `curator_note`: Авторская или кураторская концептуальная экспликация.

### 4.4. Приложение `articles` (Журнал Мастерской)
* `Article`:
  * Рубрикатор: *«Work in Progress»*, *«Архитектура и фактуры»*, *«Интерьерная керамика»*, *«Выставки и события»*, *«Экспертиза генподряда»*.
  * `author_quote`: Выделенная ключевая мысль или цитата Саши Попыкина для акцентного архитектурного блока.
* `ArticleImage`: Фотографии этапов создания с подписями стадий (`caption`) и порядком (`order`).
* `Exhibition`: Хроника выставочной деятельности (год, площадка, город, формат экспозиции, статус).

## 5. Спецификация API и интеграций

Все клиентские формы работают без перезагрузки страниц через асинхронные POST-запросы с передачей CSRF-токена в заголовке `X-CSRFToken`.

### 5.1. Эндпоинты

#### 1. Интерактивный калькулятор сметы
* **URL:** `POST /api/quiz-lead/`
* **Content-Type:** `application/json`
* **Тело запроса:**
  ```json
  {
    "name": "Алексей Смирнов",
    "phone": "+7 (999) 123-45-67",
    "company": "ПромРазвитие",
    "email": "smirnov@prom.ru",
    "object_type": "Предприятие / Завод (АБК)",
    "area_range": "1500–5000 м²",
    "service_needed": "Комплексный fit-out под ключ",
    "timeline": "В течение 1-3 месяцев",
    "estimated_cost": "от 18 000 000 ₽",
    "source": "quiz"
  }
  ```
* **Успешный ответ (200 OK):**
  ```json
  {
    "success": true,
    "lead_id": 14,
    "message": "Заявка успешно принята! Руководитель коммерческого направления Наталья свяжется с вами в ближайшее время."
  }
  ```

#### 2. Заказ кейса образцов (Architect Sample Box)
* **URL:** `POST /api/sample-box/`
* **Тело запроса:**
  ```json
  {
    "name": "Елена Архипова",
    "phone": "+7 (916) 555-77-88",
    "company": "Бюро Среда",
    "address": "г. Москва, ул. Арбат, д. 10, оф. 4"
  }
  ```

#### 3. Бронирование произведения искусства
* **URL:** `POST /api/art-inquiry/`
* **Тело запроса:**
  ```json
  {
    "name": "Михаил",
    "phone": "+7 (903) 111-22-33",
    "artwork_title": "Композиция №14: Терра",
    "artwork_id": "1",
    "message": "Хотелось бы посмотреть работу в мастерской перед покупкой"
  }
  ```

## 6. Инструкция пользователя (Руководство для Натальи и Саши)

### 6.1. Вход в систему управления
1. Откройте в браузере: `https://ваш-домен.art/admin/`
2. Введите учетные данные администратора.

### 6.2. Работа с входящими заявками (CRM)
1. В левом меню выберите раздел **«Входящие Лиды (CRM)»**.
2. В таблице отображаются все поступившие заявки с датой, телефоном, компанией и параметрами сметы.
3. **Статусы работы с клиентом:**
   * `Новая заявка` — поступила с сайта, ожидает звонка.
   * `В обработке` — контакт установлен, идет обсуждение ТЗ.
   * `Назначен выезд инженера` — согласована дата осмотра объекта.
   * `ТКП / Смета направлена` — расчет передан клиенту на рассмотрение.
   * `Заключение договора / Сделка` — успешное подписание контракта.
   * `Архив` — нецелевое обращение.
4. В поле **«Заметки Натальи / Менеджера»** можно фиксировать любые договоренности, бюджеты и дату следующего звонка.

### 6.3. Добавление нового объекта Fit-Out
1. Перейдите в раздел **«Объекты Fit-Out (Портфолио)»** → **«Добавить»**.
2. Укажите название, категорию, площадь в м², год и срок реализации.
3. Заполните поле **«Выполненные работы»**, разделяя пункты точкой с запятой:  
   `Монтаж вентиляции и СКС; Авторские рельефные поверхности стен; Изготовление стола из массива дуба и латуни`
4. Загрузите фотографию объекта через поле **«Фото объекта»**.

### 6.4. Управление Арт-Галереей
1. Перейдите в **«Арт-Галерея (Работы Саши)»** → **«Добавить»**.
2. Укажите название, размеры, материалы/технику и цену (например, `380 000 ₽` или `По запросу`).
3. Установите статус:
   * *«Доступна к приобретению»* — отображается активная кнопка резерва.
   * *«Зарезервировано»* — закреплена за покупателем.
   * *«В частной коллекции»* — отображается как проданная статусная работа.
4. Загрузите фотографию полотна или керамики.

### 6.5. Публикация в «Журнал Мастерской»
1. Перейдите в **«Журнал Мастерской»** → **«Добавить»**.
2. Выберите рубрику (например, *«Мастерская: Work in Progress»*).
3. Заполните поле **«Мысль автора / Цитата Саши»** — этот текст будет выделен архитектурным акцентным шрифтом.
4. В блоке **«Галерея процесса создания»** внизу страницы можно прикрепить сразу несколько фотографий этапов работы с краткими подписями («Первый слой минерального грунта», «Нанесение фактурной пасты»).

## 8. Инфраструктура, Docker и Production Deploy

### 8.1. Контейнерный стек (`docker-compose.yml`)
1. **web:** Контейнер приложения Django + Gunicorn.
2. **db:** PostgreSQL 16 Alpine с постоянным томом `postgres_data`.
3. **nginx:** Веб-сервер и реверс-прокси с отдачей статики (`/static/`), медиа (`/media/`) и SSL-терминацией.
4. **certbot:** Утилита выпуска и автоматического продления сертификатов Let's Encrypt каждые 12 часов.

### 8.2. Быстрый запуск на сервере (Ubuntu VPS)
```bash
# 1. Настройка окружения
cp .env.example .env
nano .env

# Обязательно укажите:
# SECRET_KEY=<случайная строка>
# DOMAIN_NAME=gb-studio.art
# POSTGRES_PASSWORD=<надежный пароль>
# TELEGRAM_BOT_TOKEN=<токен бота>
# TELEGRAM_CHAT_ID=<id чата Натальи>

# 2. Сборка и запуск контейнеров
chmod +x deploy.sh init-ssl.sh entrypoint.sh
./deploy.sh

# 3. Автоматический выпуск SSL-сертификата
./init-ssl.sh
```

### 8.3. Резервное копирование (Backup)
* **База данных PostgreSQL:**
  ```bash
  docker compose exec -T db pg_dump -U gb_studio_user gb_studio_db > backup_$(date +%Y%m%d).sql
  ```
* **Медиа-файлы (загруженные фото):**

## 9. Безопасность и регламент конфиденциальности

1. **Изоляция персональных данных и переговоров:**
   * В `.gitignore` гарантированно внесены все аудиофайлы (`*.mp3`, `*.ogg`, `*.wav`), расшифровки аудио, черновики коммерческих предложений (`COMMERCIAL_OFFER*`, `*.docx`) и локальные базы данных (`db.sqlite3`).
   * Данные клиентов, оставляемые на сайте, хранятся исключительно в изолированной базе данных и доставляются по шифрованному каналу Telegram API.
2. **Защита веб-приложения:**
   * В production-режиме (`DEBUG=False`) автоматически активируются флаги `SESSION_COOKIE_SECURE`, `CSRF_COOKIE_SECURE`, `SECURE_BROWSER_XSS_FILTER`, `SECURE_CONTENT_TYPE_NOSNIFF`.
   * В Nginx настроены лимиты запросов (`limit_req`) для защиты API-форм от спама и перегрузок.
