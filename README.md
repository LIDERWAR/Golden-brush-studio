# GB STUDIO (Golden Brush Studio)
### Платформа генподряда, архитектурного fit-out и авторского арт-ателье

Цифровой портал и система лидогенерации для архитектурно-строительного холдинга и авторского ателье **GB STUDIO** (Atelier & Fit-Out).

---

## 🏛 О проекте

Платформа объединяет два ключевых направления бизнеса:
1. **Инженерный B2B Fit-Out (Генподряд):**
   - Комплексная отделка под ключ коммерческих пространств (офисы класса A, штаб-квартиры, отели HoReCa, АБК предприятий).
   - Интерактивный 4-шаговый конфигуратор сметы с валидацией и расчетом вилки бюджета.
   - Модуль заказа презентационных кейсов для архитектурных бюро («Architect Sample Box»).
   - Допуски СРО, соблюдение стандартов СНиП/ГОСТ, работа с НДС, гарантия 5 лет.

2. **Авторское Арт-Ателье:**
   - Персональная онлайн-галерея оригинальных произведений: станковая живопись, скульптурная керамика, авторская графика.
   - Модальные экспликации работ с габаритами, материалами и прямой формой бронирования в коллекцию.
   - Институциональная хроника выставочной деятельности с 1998 года.

## 🛠 Технологический стек

- **Backend:** Python 3.12+ / Django 6.0
- **Admin & CRM:** Django Jazzmin (кастомизированная темная архитектурная тема)
- **API:** Django REST Framework (асинхронная обработка заявок без перезагрузки)
- **Frontend:** Vanilla HTML5, Vanilla CSS3 (модульная дизайн-система с токенами, адаптив от 320px до Ultrawide 3440px / 4K), Vanilla JS ES6+
- **Typography:** Cormorant Garamond, Plus Jakarta Sans
- **Database:** SQLite (разработка) / PostgreSQL (production)
- **Deployment:** Gunicorn + Nginx + Let's Encrypt SSL on Linux VPS

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/LIDERWAR/Golden-brush-studio.git
cd Golden-brush-studio
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux / macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Применение миграций и наполнение базы данных
```bash
python manage.py migrate
python seed_db.py
```
> Скрипт `seed_db.py` автоматически создает суперпользователя `admin` / `admin2026` и первично наполняет базу демонстрационными кейсами объектов и произведениями арт-галереи.

### 5. Запуск сервера разработки
```bash
python manage.py runserver
```
Сайт будет доступен по адресу: `http://127.0.0.1:8000/`  
Панель управления (CRM): `http://127.0.0.1:8000/admin/`

## 🐳 Развертывание в Production (Docker Compose + Nginx + PostgreSQL + SSL)

Подробное пошаговое руководство по настройке VPS-сервера, безопасности, файрвола и домена находится в файле **[DEPLOY.md](DEPLOY.md)**.

### Быстрый запуск на сервере:
```bash
# 1. Скопируйте и настройте переменные окружения
cp .env.example .env
nano .env

# 2. Однострочный запуск (сборка, запуск, миграции, статика, демо-данные)
chmod +x deploy.sh init-ssl.sh entrypoint.sh
./deploy.sh

# 3. Выпуск официального SSL-сертификата Let's Encrypt для вашего домена
./init-ssl.sh
```

Сервисы автоматически поднимают:
- **web**: Gunicorn + Django 6 на Python 3.12 (с автомиграцией и сбором статики через `entrypoint.sh`).
- **db**: PostgreSQL 16 Alpine с изолированным хранилищем `postgres_data`.
- **nginx**: Alpine Nginx с шаблонизацией переменных окружения (`templates/*.template`), сжатием Gzip, отдачей `/static/` и `/media/`, и защитными заголовками.
- **certbot**: Автоматическое продление SSL-сертификатов Let's Encrypt каждые 12 часов.
